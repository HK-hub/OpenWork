## 2. 新旧技术栈映射（旧契约 v4.3 → v2 基线）

| 旧组件 | 处置 | 替代/去向 |
|--------|------|-----------|
| Electron 35 + electron-vite + electron-builder | ❌ 移除 | 浏览器即客户端（D-01） |
| Ink (TUI) / Commander.js (CLI) | ❌ 移除 | 无限期搁置（D-01） |
| better-sqlite3 + sqlite-vec + FTS5 | ❌ 移除 | PostgreSQL 17（FTS 用 tsvector 承接，D-02/D-11） |
| LanceDB | ❌ 移除 | pgvector 预留（v0.2 RAG） |
| JSON-RPC 2.0 多 Transport（HTTP+SSE/WS/stdio/IPC/Embedded） | ❌ 移除 | REST + socket.io 双通道（D-12） |
| Worker Threads 进程隔离 / isolated-vm | ❌ 移除 | v0.1 无插件沙箱需求（A-05） |
| xterm.js | ⏸ 延后 | PTY 输出以卡片流渲染；完整终端面板 v0.2 评估（D-14） |
| node-pty | ✅ 保留并前置到 v0.1 | 交互命令人工接管核心依赖 |
| TipTap 富文本输入 | ⏸ 延后 | v0.1 textarea（D-15） |
| @lobehub/* | ❌ 已废弃（旧档 v4.3 即退役） | antd v5 + Tailwind v4 |
| Handlebars 模板引擎 | ⏸ 延后 | PROMPT 域 v0.2 再评估；引擎内部插值用轻量函数 |
| web-tree-sitter / chokidar | ⏸ 延后 | 随 RAG/文件监听需求进 v0.2 |
| MCP SDK (@modelcontextprotocol/sdk) | ⏸ 延后 | v0.2 MCP Client |
| Fastify / ws 裸库 | ❌ 移除 | NestJS 默认 Express 底座 + socket.io |
| Vitest / Playwright | 🟡 部分 | Vitest 保留；Playwright E2E 推迟（先 supertest 冒烟） |

## 3. 关键依赖安装清单

```bash
# ===== root =====
npm i -D turbo@^2
npm i -D typescript@^5.7 eslint@^9 prettier@^3 husky lint-staged dependency-cruiser

# ===== packages/contracts =====
npm i zod@^3.24          # 类型与schema的唯一来源,零其他依赖

# ===== apps/server =====
npm i @nestjs/core@^11 @nestjs/common@^11 @nestjs/platform-express@^11 \
      @nestjs/cqrs@^11 @nestjs/event-emitter@^11 @nestjs/swagger@^11 \
      @nestjs/config@^11 @nestjs/websockets@^11 @nestjs/platform-socket.io@^11
npm i socket.io@^4 drizzle-orm postgres zod pino nestjs-pino node-pty
npm i openai @anthropic-ai/sdk
npm i -D drizzle-kit @types/node vitest supertest @nestjs/testing

# ===== apps/web =====
npm i react@^19.1 react-dom@^19.1 antd@^5.22 \
      react-resizable-panels@^2.1 zustand@^5 @tanstack/react-query@^5 \
      socket.io-client@^4 \
      react-markdown remark-gfm rehype-highlight rehype-sanitize
npm i -D vite@^6 @vitejs/plugin-react tailwindcss@^4 \
      @monaco-editor/react@^4.7 monaco-editor@^0.55
```

> `node-pty` 为原生模块：Windows 需 VS Build Tools；CI 提供 prebuild 缓存。安装失败时的降级路径：`run_command` 退化为 `child_process.spawn` 非交互模式（功能受限，ADR 记录）。

## 4. docker-compose.yml 基线

```yaml
services:
  postgres:
    image: pgvector/pgvector:pg17        # 自带 pgvector 扩展,v0.1 不启用
    container_name: openwork-postgres
    environment:
      POSTGRES_USER: openwork
      POSTGRES_PASSWORD: openwork        # 仅本地开发;生产由 env 注入
      POSTGRES_DB: openwork
    ports:
      - "127.0.0.1:5432:5432"            # 只绑回环
    volumes:
      - openwork_pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U openwork"]
      interval: 5s
      timeout: 3s
      retries: 10
volumes:
  openwork_pgdata:
```

- ❌ Next.js / Nuxt（SPA 已锁）
- ❌ @lobehub/* 全家桶（历史遗留，禁止回流）
